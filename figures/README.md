# Figures

This directory stores figures generated by the reproduction scripts.

Generated figures are organized by the original experiment family, for example:

```text
figures/
├── PNP_code/
│   ├── PNP_ex1_paper/
│   ├── PNP_ex2_paper/
│   ├── PNP_ex3_paper/
│   └── PNP_ex4_paper/
└── PNPNS_code/
    ├── PNPNS_results_ex1/
    └── PNPNS_results_ex2/
```

## Figure 10

Paper Figure 10 is generated by:

```bash
python experiments/example4_3/PNP_ex3_st_re.py
```

The script writes:

```text
figures/PNP_code/PNP_ex3_paper/PNP_r_ex3_paper/SO-RaNN/PNP-st-re-ex3-p.eps
figures/PNP_code/PNP_ex3_paper/PNP_r_ex3_paper/SO-RaNN/PNP-st-re-ex3-p.png
```

The `.png` copy is provided for convenient preview on systems that do not open
EPS files by default.

If the numerical solve has completed once and the final plotting step needs to
be regenerated, use:

```bash
python experiments/example4_3/PNP_ex3_st_re.py --plot_only
```

This uses saved checkpoints from `results/checkpoints/PNP_code/model_ex3/` and
the saved scaler from `results/PNP_code/example4_3/scaler.pt`.

## Repository Policy

Keep final paper figures or small representative outputs only when needed.
Large batches of temporary images should be regenerated from `experiments/`
instead of committed.
